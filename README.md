# Energy Asset Monitor

A Python OOP project that simulates gas turbines, wind turbines and transformers, and flags assets that need maintenance.

## Concepts used
- Abstraction (abstract Asset class)
- Inheritance (GasTurbine, WindTurbine, Transformer)
- Polymorphism (each asset calculates its own output)
- Encapsulation (private health value)

## Run
python main.py
